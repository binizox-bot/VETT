# 导出范围、完整性与恢复边界

## 实际收录范围

`manifests/EXPORT_SCOPE.json`冻结了67个工作区顶层条目，以及62份已识别相关已保存材料的名称与来源身份。工作区条目递归收录全部现有普通文件，包括失败预测、旧报告、复述/修订消融、阶段目录、重复文件、缓存副本和历史压缩包；空目录也保留。

本次载荷清点为2,654个文件、917,753,215字节（约875.24 MiB），其中工作区文件2,592个、已保存快照62个。文件级内容SHA-256有1,813个不同值；重复内容保留，不做去重删除。精确数字见`SOURCE_AUDIT.json`；ZIP还包含新增维护文档、脚本、清单与本次验证日志。

62份已保存快照中，48份与至少一份同名本地材料字节一致，14份为额外找回的同名缺失材料。14份包含早期样本、单篇实验报告、方法参考清单和论文PDF的历史副本；它们不代表14项新的模型实验。

## 完整性凭证

| 文件 | 核验职责 |
| --- | --- |
| `PAYLOAD_MANIFEST.json` | 每个历史载荷文件的归档路径、字节数、SHA-256、mtime和权限位 |
| `FULL_MANIFEST.json` | 历史载荷与本次新文件的完整SHA-256清单；自身由外层ZIP校验覆盖 |
| `HISTORICAL_ZIP_AUDIT.json` | 57个既有ZIP的完整CRC扫描，失败数为0 |
| `HISTORICAL_ZIP_MEMBERS.jsonl` | 每个旧ZIP的内部成员、字节和CRC索引；帮助查找已被工作区覆盖的版本 |
| `SAVED_SNAPSHOT_RECONCILIATION.json` | 已保存快照与本地同名文件的逐项比对 |
| `DUPLICATE_CONTENT_GROUPS.json` | 同SHA-256文件清单；保留每个路径与版本上下文 |
| `STATIC_CODE_AUDIT.json` | 当前源码静态解析、JSON解析检查、import与绝对路径引用索引 |
| `verification/smoke/` | 本次安全离线复核的原始日志、评分与35项结果 |

独立验证器会比对ZIP的完整普通文件集合、逐文件字节与SHA-256、重复成员路径，并执行CRC扫描。最终ZIP另有外部SHA-256和验证回执，避免将ZIP自身哈希写进ZIP造成循环依赖。

## 保留原貌与安全

- 历史文件内容未做格式化、修正、删重或重命名。
- 原始主工程目录保留原相对层级，以便其兄弟上游数据目录仍可被定位。
- 文件级内容哈希是身份依据；读取或保存产生的操作系统元数据差异不视为内容变化。
- 不打包运行平台环境、认证资料、无关账户材料或本次临时传输控制文件。静态高置信度密钥模式检查未命中；这不构成专业安全审计。
- 本ZIP无加密，包含私有金标和历史预测；请按内部研究资料管理。对外发布必须另建仅含允许公开内容的包。

## 不能凭本次导出恢复的材料

1. 未落盘的完整聊天记录、后台上下文、隐藏推理和模型服务日志。
2. 曾被覆盖且未保存在任何可访问快照中的失败候选原件。
3. 从未取得的观测逐球数据、外部项目仓库、模型权重、API密钥和远程运行环境。
4. 其他聊天中的足球论文、求职或旅行材料；本次范围聚焦当前板球数据集项目及其本地前期试点。

因此可验证的完整性承诺是：**所有枚举到的现有项目文件均保留并可逐项校验。** 对不存在或不可访问的历史原件不作恢复承诺。旧报告中的“全部通过”仅保留原实验定义，不被本归档自动升级为新的科学结论。
