# R4 jointly constrained state reconstruction

## Research question

R4 tests whether a system can select one globally valid match state when two
locally coherent event assignments survive. It is not a longer-text or hidden-
schema test. The value-free target rows and columns remain visible.

## Tracks

- Primary: 12 scalar cells per root. Only this track controls the hardness gate.
- Secondary: 4 composite cells per root with exact cricket serialization rules.

## Joint-block requirements

Each root has two blocks. Every block must:

1. connect at least six primary scalar cells;
2. contain two locally coherent candidate states;
3. differ on at least four target cells;
4. require event identity, source authority and one conservation/legal-ball
   constraint to choose the accepted state;
5. spread decisive evidence over at least three documents and six paragraphs;
6. avoid a paragraph that enumerates the complete accepted ledger;
7. preserve the canonical scorecard as the unique globally compatible state.

Candidate states and delta vectors are private construction metadata. Public
documents describe the conflicting feeds and event signatures, never the
candidate value vector.

## Gate

- canonical gold preservation: 100%;
- semantic oracle: 100%;
- no forbidden private IDs in the blind package;
- no target final-value sentence introduced by the R4 overlay;
- leave-one-constraint-out ablations must admit the alternate state;
- all-constraint symbolic audit must leave exactly one state;
- primary scalar strong-model error target: at least 20% with omission below
  10%, before any six-method expansion.

## Scientific boundary

R4 is developed only on match_0185, match_0106 and match_0178. Test roots are
untouched. A self-check performed in the construction context is a mechanism
diagnostic, not an independent model result.
