# R13-C public preview

The blind instance contains six source documents and 17 atomized target rows. The full machine-readable input is `blind/r13c_blind.jsonl`.

The task instruction is:

> Fill every null atomic cell. Conflicting scorer rows must be resolved jointly from cricket score conservation, wicket chronology and the uncontested leaves. Neither scorer source is globally authoritative; source order and repetition are not authority.

The public bundle contains no gold labels, truth flags, private evidence chains or scorer answers. It does contain both candidate values, because candidate adjudication is the task itself.
