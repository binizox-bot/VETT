## 从这里开始

1. 将压缩包解压到短路径，例如`C:\vett`或`/work/vett`。路径包含中文、空格和历史长文件名，建议使用支持UTF-8与ZIP64的解压工具。
2. 阅读[研究沿革与结果边界](docs/01_HISTORY_AND_RESULTS.md)和[已知问题](docs/05_ISSUES_AND_NEXT_ITERATION.md)。历史README和“PASS”标签具有各自版本范围。
3. 通过[全版本文件索引](docs/02_VERSION_FILE_INDEX.md)进入所需实验。当前工程位于`workspace_snapshot/vett_cricket_pilot_v1/`；旧发布包、早期试点和临时验证目录均保留在`workspace_snapshot/`。
4. 按[复现与维护手册](docs/03_MAINTENANCE_AND_REPRO.md)核验哈希、运行安全自检。所有新输出放入新目录。
5. 交给下一位开发者时，直接使用[Agent交接指令](docs/07_AGENT_HANDOFF.md)。
