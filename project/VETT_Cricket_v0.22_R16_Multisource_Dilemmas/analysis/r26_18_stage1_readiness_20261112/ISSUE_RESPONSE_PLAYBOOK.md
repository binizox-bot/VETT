# 数据集优化问题处置手册

## 总原则

一次只处理一个主要假设。先判定问题属于数据、协议、测量、模型、provider、统计、语言、安全、许可或成本，再只修改对应层。R26.15不得原地修改；合法数据改动必须建立新 shadow 候选。

## P0：立即隔离

适用：密钥泄露、未授权费用、冻结候选被覆盖、public混入private gold、受限响应泄漏、明确许可禁止。

动作：停止全部执行，冻结日志和哈希，隔离产物，记录影响范围；不得继续测试或“顺手修复”掩盖现场。需要新的安全/恢复决策后才能重入。

## P1：阻断正式结果

适用：候选漂移、Oracle非100%、金标权限冲突、图环/非法端点、反事实多原子改变、answer-prior捷径、硬协议失败、评分器错误。

动作：保存不可变证据并停止正式结论。数据问题建新候选；协议问题建新协议；评分问题只对原始响应做版本化本地重放。修复后重跑全门。

## P2：限制声明

适用：样本不足、bootstrap区间过宽、锚点×等级缺单元、两模型方向相反、人工分歧集中、语言表面不自然。

动作：保留结果但降级声明，补齐预注册证据或人工仲裁；不得移动阈值、改采样单位或把探索性切片包装成主结论。

## P3：记录并排期

适用：文档缺失、非关键格式、工具易用性、不会改变正确性/身份/统计结论的问题。

动作：进入版本化待办，说明影响和验证方法；不得与P0/P1混在同一“优化批次”发布。

## 关键场景决策表

| 场景 | 立即动作 | 合法重入条件 | 禁止做法 |
| --- | --- | --- | --- |
| 候选哈希漂移 | 停止并定位首个差异 | 恢复冻结副本或建新候选，重跑全门 | 手改manifest/hash |
| 主指标>65% | Sentinel只登记偏易假设 | Pilot20至少4题/2锚点复现后才可建shadow | Sentinel后直接加难 |
| 主指标<35%或L1<60% | 禁止加难 | Pilot20确认后仅可做L1/L2单负担减法shadow | 增加噪声/证据负担 |
| 相邻下降<8点或倒置 | 切片定位弱相邻对 | Pilot20跨至少2锚点、4题复现 | 全局重做五级 |
| HTTP 429/503/402/timeout | 停止并冻结工件 | 核实状态、账单；新run和新授权 | 自动重试或记语义零分 |
| ambiguous in-flight | 隔离请求claim | 先查终态与账单 | 未确认前重发 |
| 非法JSON/截断 | 硬失败 | 新协议或新模型兼容性诊断 | 修补后转正 |
| 重复证据 | 集合语义计分并标nonconformant | 并列报告重复与语义 | 静默去重或给额外信用 |
| 评分代码错误 | 保留原始响应 | 新评分版本本地重放与勘误 | 覆盖旧报告 |
| public含private gold | P0隔离并作废包 | 白名单重打包与全量泄漏扫描 | 只删已发现文件 |
| 许可不清 | 阻断公开发布 | 来源许可矩阵完成 | 默认公开网页可再分发 |

## shadow优化十步闭环

1. 有效Pilot20、人审或确定性测试发现问题；
2. 归类根因；
3. 定界题/等级/锚点/关系/字段；
4. 在看新结果前登记一个假设；
5. 检查当前调整权限；
6. 复制建立新shadow，不覆盖R26.15；
7. 完成Oracle、countermodel、变异、反捷径、语言、容量和确定性重建；
8. 对受影响的注册单元做单独授权的最小外测；
9. 由第二强模型家族在未改R26.15上确认触发方向；
10. 满足fresh shadow Sentinel等门后晋升，否则保留证据并丢弃shadow。
