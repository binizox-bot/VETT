## 2. 四轨报告

### 2.1 可用性轨

逐场报告 HTTP/终态、延迟、输入/输出/推理/缓存 token、估算与实际费用、停止原因。可用性失败不得记作语义零分。

### 2.2 硬协议轨

报告 JSON/schema、exact target map、ID、字段类型、关系、图端点、原始数组上限、未知 span 形状及 batch 状态。任何硬失败使正式语义成绩失去资格。

### 2.3 服从性轨

报告完全相同重复证据组、冗余数量、题级 conformance 和 exact-duplicate 行为。合法重复按集合语义计分，但题目标记 nonconformant；不得给重复额外信用。

### 2.4 语义轨

只在正式资格通过时报告主指标和辅助指标；集合语义与原始服从性并列，不能互相替代。

## 3. 主指标与五级曲线

- `decision_field_level_macro_accuracy`：
- L1 / L2 / L3 / L4 / L5：
- L1→L2、L2→L3、L3→L4、L4→L5：
- 正向下降数量：
- 平均相邻下降：
- Sentinel方向筛查：至少3个相邻下降为正，平均下降至少8个百分点。

Sentinel5只有每级5个观测，点估计分辨率为20个百分点，只做方向筛查，不作稳定论文估计。

## 4. 必做切片

- 12个事实字段；
- 私有等级；
- 5个锚点家族；
- 情景类型；
- 关系类型；
- 正证据、排除证据与内容依赖边；
- 检索失败、关系失败、反事实失败、输出服从性失败；
- 完全重复与未知证据引用。

每个发现必须标成：`正式筛查 / 辅助诊断 / 探索性`。

## 5. 冻结决策规则

| 观察 | 允许结论 | 下一动作 |
| --- | --- | --- |
| 主指标45%–65%、L1≥60%、方向筛查通过 | 值得扩大验证 | 另行申请第一家族Pilot20 |
| 主指标>65% | 可能偏易 | 登记一个错误机制假设；不得改题 |
| 主指标<35%或L1<60% | 地板效应风险 | 禁止加难，先审查协议与L1/L2负担 |
| 主指标35%–45% | 决策灰区 | 扩大诊断或承认证据不足 |
| 45%–65%但曲线不通过 | 等级稳定性存疑 | 登记弱相邻或倒置假设，交Pilot20验证 |
| 硬协议失败 | 无正式难度结论 | 只修协议，新run需新授权 |

## 7. 声明边界

- 可以声明：完整性、四轨观测、Sentinel方向筛查和待验证假设。
- 不能声明：五级难度已稳定、数据已优化成功、跨模型泛化、220场表现或shadow可晋升。
