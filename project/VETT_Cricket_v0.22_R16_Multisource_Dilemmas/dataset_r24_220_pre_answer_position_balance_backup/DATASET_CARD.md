# VETT-Cricket R24 High-Difficulty Full Release

R24 contains **220 matches** and preserves every R22 Track A table target and Track B evidence probe. Each match adds one rule-application item at each of L1-L5 and five open grounded-reasoning items.

The rule track uses 60 independently identified scenarios under **Laws of Cricket 2017 Code, 4th Edition 2026** (effective 2026-10-01). Evidence is dispersed across documents with level-specific decisive and misleading roles. Every text mutation is reversible; each instance is rebuilt to its exact R22 document digest during audit.

Static validation proves structural consistency, exact gold reconstruction, scenario coverage, split isolation, evidence-role integrity, mutation-budget compliance and oracle scorability. It does **not** prove the preregistered strong-model accuracy ceiling or adjacent-level gaps; those remain empirical calibration claims until a model panel is run.

Use only `public/` as model input. Keep `private/`, `audit/` and oracle outputs outside solver context.
