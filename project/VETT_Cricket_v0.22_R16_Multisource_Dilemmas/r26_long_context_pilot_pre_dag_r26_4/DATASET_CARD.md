# VETT-Cricket R26.4 typed-evidence-graph pilot

R26.4 is a 20-match, 100-question pilot built additively on the frozen R25.2 diagnostic pilot. It preserves every R22 table target and evidence probe and every R25 factual, state, ledger and counterfactual answer.

R26.4 replaces the synthetic CASE/OBS/PKT surface layer with cricket-native identity chains using match entities, over references, scorer sheets, commentary reconciliation and review timing. Each incident contains at least one same-event source conflict. L1/L2 require a separate incident-specific authority span; higher levels retain their existing temporal and source-policy topology. The registered L1--L5 identity depths remain 1/2/3/4/5. The complete R25 proof graph remains a subset, and public difficulty labels are removed.

Unlike earlier R26 pilots, the answer contract requires an explicit minimal directed proof graph. Its typed edges distinguish identity resolution, authority selection, accepted facts, rejected same-event claims, governing rules and support for the final decision. Evaluation reports span F1, typed-edge F1, span-and-edge exactness, and factual-record-plus-proof-chain exactness separately; a model cannot receive proof-chain credit merely by returning a bag of plausible span IDs.

Each match also has head, middle and tail position forms with identical span IDs and text. These forms are robustness controls, not extra independent test items. Use only `public/` or a declared `variants/<form>/public/` form as model input. Never expose `private/` or `audit/`.

Static PASS proves deterministic gold, R25/R22 reconstructability, one-fact counterfactuals, deterministic typed proof graphs, natural-identity bridge coverage and position-form invariance. It does not prove empirical five-level separation; that requires the preregistered model panel.
