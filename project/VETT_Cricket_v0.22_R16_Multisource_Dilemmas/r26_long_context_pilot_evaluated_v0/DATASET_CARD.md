# VETT-Cricket R26 long-context stability pilot

R26 is a 20-match, 100-question pilot built additively on the frozen R25.2 diagnostic pilot. It preserves every R22 table target and evidence probe and every R25 factual, state, ledger and counterfactual answer.

R26 replaces the synthetic CASE/OBS/PKT surface layer with cricket-native identity chains using match entities, over references, scorer sheets, commentary reconciliation and review timing. Every item adds a necessary semantic bridge while retaining the complete R25 proof graph as a subset. Public difficulty labels are removed.

Each match also has head, middle and tail position forms with identical span IDs and text. These forms are robustness controls, not extra independent test items. Use only `public/` or a declared `variants/<form>/public/` form as model input. Never expose `private/` or `audit/`.

Static PASS proves deterministic gold, R25/R22 reconstructability, one-fact counterfactuals, natural-identity bridge coverage and position-form invariance. It does not prove empirical five-level separation; that requires the preregistered model panel.
