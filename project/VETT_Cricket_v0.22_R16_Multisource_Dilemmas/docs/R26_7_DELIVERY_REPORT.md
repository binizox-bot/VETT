# R26.7 交付与晋级报告

## 结论

R26.7 已完成20场pilot的权限绑定修复：事实span只暴露中性来源别名，签名、修订号、锁定时间及控制关系只在必要权限span中出现。跨比赛来源文体宏F1从R26.6的77.7%降到54.6%，通过60%门槛；全量Oracle、静态审计、快捷审计和108项回归通过。外部模型仍因账户HTTP 402未能运行，所以暂不批准扩到220场。

## 为什么R26.6仍不够

R26.6解决了固定句式，却没有消除来源角色指纹：被采信事实总是写成签名观察、修订9或锁定前记录；冲突则写成未签名feed、修订2或锁定后记录。移除实体和事实内容后，等先验Naive Bayes跨比赛留一仍达到77.7%宏F1、87.8%平衡准确率。这意味着模型可以绕过本应必要的权限证据。

## R26.7设计

每道题确定性选择一对自然来源别名，例如“west-cabinet sheet”和“east-cabinet sheet”，并平衡哪个别名承载采信事实。事实span对两类来源使用同一组句式，不写签名、修订号或时间。必要权限span才说明：

- 哪个别名是签名在场观察、哪个是未签名feed；或
- 哪个别名是签名修订9、哪个是修订2；或
- 哪个别名在18:22签署、哪个在18:29且越过18:25锁定。

因此，模型必须把中性别名与权限span连接后，才能建立`authorizes`和`rejects`关系。

## 无回归与难度

R26.6到R26.7保持不变：100道题干、事实记录、状态、反事实、正/排除证据ID、2,492条类型边、文档位置和1/2/3/4/5身份深度。共996/28,574个公开span只做来源表述替换。

逐场估算上下文增加15–81 token，平均增加50.1 token；5道题由32K档升到64K档，没有题目向更低档移动。L3–L5字面top-k召回为23.0%/19.9%/17.9%，仍远低于45%门槛。

## 审计结果

- 来源文体baseline：宏F1 54.6%，平衡准确率58.8%，PASS。
- 最大骨架占比：权限冲突10%、权限策略5%、采信事实1.83%、同事件冲突2.78%、身份桥8.13%，PASS。
- 静态发布：20/20场、100题PASS；公开等级泄漏0。
- Oracle：20个batch全部OK；事实、正span、排除span、edge、完整链均100%。
- 两次独立构建manifest SHA-256一致。
- 全仓回归：108/108 PASS。

## 仍然存在的边界

这些结果证明已知模板和来源文体捷径受到控制、金标闭环可复现；不证明强模型事实宏准确率已经低于65%，也不证明相邻等级至少相差8个百分点。免费模型仍被账户级HTTP 402在生成前拦截，0 token、0费用、0语义覆盖；余额未变化前不重复请求。
