## 客观限制

只有每级2题，不能据此确认相邻等级至少8个百分点，也不能宣称强模型总体事实准确率已经稳定低于65%。当前结果足以证明“类型化证据链比span选择显著更难”，但不足以完成五场校准。

此外，关系类型混淆可能同时包含模型能力不足和任务 ontology 说明不够显式两种因素。正式续跑前应在评测提示中逐条定义七类边的方向和合法节点类型；这不会泄露答案，只会避免把标签协议猜测误当成证据推理失败。随后必须用新的 prompt 版本和新 run ID 运行剩余五场，不能与本次隐式 ontology 结果混合。
