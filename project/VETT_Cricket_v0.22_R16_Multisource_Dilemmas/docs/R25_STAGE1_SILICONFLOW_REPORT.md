# R25.2 SiliconFlow 第一阶段筛选报告

## 结论

第一阶段已经完成，但不建议立即扩展到 220 场。

同一套 C2-Table 协议下，GLM-5.3-Flash 的事实完整记录准确率为 32%，DeepSeek-V4.1-Flash 为 40%，均低于预设的 65% 上限。数据集的整体难度已经足够，主要问题不是“还不够难”，而是五级难度在不同模型之间不稳定。

## 固定协议

- 5 场比赛、25 个问题，每个场景族恰好出现一次。
- 每场五题合并为一次调用，保持长文本、多事件绑定和联合序列化压力。
- 两个可评分模型使用相同公开输入、问题、答案结构和评分器。
- GLM 复用已有有效结果，没有重复收费；DeepSeek 新增完整五场运行。

## 最重要的诊断

1. **总体难度合适。** 两个强模型的事实完整准确率均显著低于 65%，不需要继续无目的增加噪声或文本长度。
2. **证据链仍有区分度。** DeepSeek 的事实字段更强，但最小证据 F1 仍只有 58.0%，事实答案正确不等于证据链完整。
3. **反事实是稳定瓶颈。** 两模型的事实与反事实联合正确率只有 20% 和 28%。
4. **等级顺序尚未跨模型成立。** GLM 的 L3 与 L4 持平；DeepSeek 的 L3 明显高于 L2，L4 与 L5 持平。25 题每级仅 5 题，完整准确率以 20 个百分点跳变，不能据此直接重写全部题目。
5. **L2/L3 的操作类型分配需要复核。** L2 中复合计分、Wide/Stumped 和 No-ball-over-Wide 场景对两个模型都很难；L3 中 LBW、Caught 和 keeper exception 对 DeepSeek 反而较容易。需要调整分层或场景构成，而不是削弱现有证据链。

## 下一步门槛

在扩展 220 场之前，应先进行以下最小修订：

1. 保留当前事实、证据、反事实和隐状态难度，不删除已有困难机制。
2. 根据两个模型共同错误与分歧，重新审查 L2/L3 的场景归属和组合比例。
3. 将 20 场、100 题全部用于 GLM 与 DeepSeek，得到每级 20 题后再判断 8 个百分点间隔。
4. 若需要第三模型，先解决统一输出长度约束，不能改成逐题调用后与五题合并结果直接比较。
