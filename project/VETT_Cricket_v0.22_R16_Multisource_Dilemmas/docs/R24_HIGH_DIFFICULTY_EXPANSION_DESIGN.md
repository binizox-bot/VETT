# R24 高难度扩展设计与实施边界

## 1. 设计结论

R24 不应通过继续加长文本或增加无关噪声来制造难度。上一轮 `match_0066` 的 GLM-5.3-Flash 结果是规则答案 5/5、联合证据 2/5，说明当前问题是“答案过易，证据角色较难”。下一版必须同时提高答案推导难度和证据链难度，并分别报告二者，禁止用低联合精确率掩盖事实答案过于简单。

R24 仍然是 R22/R23.1 的增量层：保留整表恢复、五类证据探针和开放解释；只对未参与原金标准的路由噪声做小量可逆替换，再插入少量规则事实、局部条件、错误解说和最终裁定。

本设计的机器合同位于 `design/r24_high_difficulty_blueprint.json`。它包含 12 个规则簇、60 个独立场景、每级12个场景，以及生成和验收门槛。当前状态明确标记为 `DESIGN_ONLY_NOT_GENERATED`。

## 2. 相比 R23.1 的关键升级

### 2.1 从10个记忆题扩展为60个独立场景族

覆盖12个规则簇：无球、宽球、死球与一轮、跑分与边界、击球相关出局、跑动相关出局、申诉与球门状态、守场员/守门员/替补、击球员/代跑/练习、比赛生命周期与结果、场地/线/器材、不公平比赛与罚分。

每个场景必须有独立的规则引用、答案类型和推导机制。表面改写不算独立场景；同一规则换姓名、数字或文体也不增加独立样本数。

### 2.2 从“找到一句答案”升级为状态组合

高等级题不直接把规则结论写进文本，而是分别给出：

- 投球是否合法；
- 球在何时成为死球；
- 击球员或守场员当时的位置/资格；
- 是否存在跑动、触球、边界或申诉；
- 哪一条解说是临时判断；
- 哪一个局部比赛条件覆盖默认规则。

模型必须组合这些状态才能得到答案。每个 L5 场景至少涉及3条规则，并带有一个只改变单一条件、但会改变答案的反事实孪生题。

### 2.3 区分三种文本角色

- `decisive`：直接参与当前题推导。
- `misleading`：直接讨论当前题，但内容错误、过时或权限不足。
- `irrelevant`：属于其他规则或其他作用域；不是误导证据，模型必须忽略。

这一边界必须公开写入任务说明。评分时分别计算决定性证据召回、误导证据精确率和作用域归属准确率，避免把无关文本误判为误导文本。

### 2.4 不再让难度只依赖精确集合匹配

主结果分成四层：

1. 事实答案是否正确；
2. 规则应用原子是否正确；
3. 决定性、误导性和无关证据是否正确分流；
4. 答案、推理和证据是否全部联合正确。

论文必须首先报告事实答案宏平均，再报告证据指标。联合指标是严格上限，不替代事实指标。

## 3. 五级难度合同

| 等级 | 文本结构 | 推理要求 | 强模型事实准确率目标 |
| --- | --- | --- | ---: |
| L1 | 单条经过释义的明确规则线索 | 一条规则、一次定位 | 78%–86% |
| L2 | 两条互补线索位于不同文档，或规则带一个例外 | 合并两条事实并选择例外 | 67%–75% |
| L3 | 两条规则形成状态链，加入时间或作用域变化 | 跟踪中间状态，排除一个近似答案 | 56%–64% |
| L4 | 可信错误解说、正式裁定和局部作用域同时出现 | 权限判断、冲突消解、最终状态 | 43%–52% |
| L5 | 至少三条规则、3–5条决定性证据、反事实孪生 | 多规则组合并验证答案随单一条件翻转 | 28%–40% |

五级目标区间的中点宏平均约为59.9%，低于65%；相邻区间中心至少相差10个百分点。实际发布门槛仍要求相邻等级事实准确率下降不少于8个百分点。

## 4. 文本增量与不降级约束

每场最多：

- 替换7个未被 R22 表格或探针引用的路由 span；
- 插入9个规则 span；
- 触及原始 span 不超过1.2%；
- 所有操作保存私有逆向补丁；
- 逆向恢复后，R22 文档、表格金标准和探针金标准摘要必须完全一致。

新增文本不能集中在文末，也不能使用固定“权威/错误”标签。L2–L5 的决定性线索必须跨文档；同一题的证据位置、表面句式、文体和出现顺序由种子确定，但事实结果不由随机数决定。

## 5. 场景构造方式

每个场景由以下对象组成：

```text
rule_source        固定版本的官方规则及条款
case_facts         本题独有的比赛状态事实
local_conditions   可选；必须在文本中明确版本和适用范围
state_transitions  provisional → corrected → final
decisive_claims    推导答案所需的最小事实集合
misleading_claims  直接相关但错误/过时/越权的说法
irrelevant_claims  其他题或其他作用域的正确事实
gold_derivation    规则原子、状态节点、边和最终答案
counterfactual     只改变一个条件且必须改变答案
```

金标准必须由确定性规则函数生成，不能由语言模型自由撰写。语言模型只可用于生成候选释义，候选释义随后必须通过规则一致性、实体作用域、数字守恒和反事实翻转检查。

## 6. 60个场景的分配

机器蓝图在每个规则簇中各放置一个 L1、L2、L3、L4、L5 场景，因此每级恰好12个，合计60个。典型 L5 包括：

- 无球＋跑出＋过投边界＋已完成跑分；
- 宽球＋守门员位置＋离地状态＋击杀；
- 死球/无球/宽球调用链与一轮是否结束；
- 跑分＋边界＋球门状态＋出局时点；
- 替补资格＋边界接触＋接杀完成；
- 代跑员＋击球员离地＋跑动意图＋跑出/击杀分类；
- MCC默认规则与明确版本化的局部比赛条件冲突；
- 多种罚分、额外分和已完成跑分的合并次序。

完整的60个场景ID、规则范围、答案类型和机制见机器蓝图，避免设计文档与实现合同出现两套定义。

## 7. 指标体系

### 7.1 事实与规则

- `fact_answer_macro_accuracy`：五级等权宏平均，论文主要难度指标。
- `rule_application_atom_micro_f1`：规则步骤是否选对。
- `counterfactual_pair_consistency`：原题与孪生题是否同时正确且发生预期答案翻转。

### 7.2 证据与作用域

- `decisive_span_micro_f1`；
- `misleading_span_micro_f1`；
- `scope_assignment_accuracy`：decisive/misleading/irrelevant 三分类；
- `reasoning_edge_micro_f1`：规则、状态和证据之间的有向边；
- `answer_reasoning_evidence_joint_exact`。

### 7.3 可靠性

- `confidence_brier_score`；
- 缺失答案率、无依据答案率、矛盾解释率；
- 按规则簇、答案类型、文本机制和文档跨度分别切片。

开放式说明只作为次级人工/语义评分；可复现的结构化指标仍是主评分。

## 8. 数据切分与防泄漏

60个场景按“场景族”切分，而不是按比赛随机切分：开发30、校准15、最终测试15。同一场景族的改写、反事实和不同人物版本不得跨越切分。最终测试集生成后禁止继续根据模型错误修改提示或题型。

文本模板需满足：新增 span 全句重复率为0；高频4-gram和开头指纹设置上限；答案选项位置平衡；规则簇、级别、答案类型和证据角色在比赛之间做拉丁方分配。唯一案卷号只能用于引用，不能编码等级、权威性或答案。

## 9. 校准与发布门槛

设计落地后的顺序必须是：

1. 先用 Oracle 验证所有事实、证据、边和反事实为100%；
2. 用至少一个强模型、一个中等模型进行15场校准，不接触最终测试族；
3. 强模型事实宏平均必须不高于65%；
4. 相邻等级事实准确率下降至少8个百分点；
5. 若答案准确率过高，优先增加规则组合和例外条件，禁止仅增加噪声；
6. 若证据低但答案高，不能宣称整体难度达标；
7. 若 L4/L5 比 L2/L3 更容易，修改机制而不是重新命名等级；
8. 通过后才允许扩展到220场。

每级校准样本不足60题时，不对8个百分点差距作确定性结论；应同时报告 Wilson 区间或按场景族 bootstrap 的置信区间。

## 10. 实施状态与边界

R24现已从R22全量根生成到 `dataset_r24_220/`：220场静态审计通过，60个场景全部覆盖，Oracle评分闭环通过。实施时保留本设计的难度下限，并用每场6次可逆替换加9次插入满足15个最低证据片段；最大基础span触碰率为0.793651%。

这里的“静态通过”只证明构造可恢复、金标一致、证据角色完整、场景切分隔离和评分器闭环。尚未运行R24外部强/中模型组，因此强模型事实宏平均不高于65%、相邻等级至少8个百分点差距仍是待检验目标，不得写成已达到结果。全量生成是发布候选，不会替代后续校准与必要修订。
