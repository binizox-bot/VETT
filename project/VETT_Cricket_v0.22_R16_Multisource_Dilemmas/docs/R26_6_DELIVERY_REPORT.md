# R26.6 交付与晋级报告

## 追溯结论（已由R26.7替代）

R26.6 曾完成20场pilot的自然表述去模板化，并通过当时的静态审计、快捷方式审计、全量Oracle与107项回归。R26.7新增来源文体分类门后，R26.6以77.7%宏F1和87.8%平衡准确率追溯FAIL：模型仍可能不读权限span就判断来源角色。本版本冻结为失败对照，不再是当前候选。

## 本轮发现的问题

去掉已登记的人名、事件标签、事实子句、时间和编号后，R26.5仍有明显文体指纹：

- 权限策略最大单模板占100%；
- 被采信事实最大单模板占52.4%；
- 新增权限冲突最大单模板占40%；
- 既有同事件冲突最大单模板占38.9%；
- 身份桥最大单模板占25%。

这不会直接泄露答案，但会让模型先用句式猜证据角色，再减少真正的身份绑定与来源判定负担。原来的“精确重复为0”无法发现它。

## R26.6改动

渲染器为身份桥、权限合同、采信事实、冲突事实和规则摘录增加多个确定性自然表述族，并使用问题与实体哈希稳定选择。没有随机在线改写，也不依赖模型生成，因此同一seed可字节复现。

R26.5到R26.6保持不变的内容包括：

- 20场、100道公开题干；
- 事实记录、潜在状态和单事实反事实；
- 正证据span、排除证据span；
- 2,492条类型边与七类关系；
- 25个场景家族和L1–L5的1/2/3/4/5身份深度；
- 文档归属和位置变体。

只有自然文本表述发生变化。估算上下文长度的逐场变化为-42至+35 token，平均约+1.1 token；所有结构难度维度不变。

## 审计结果

新版各角色最大骨架占比：权限冲突30%、权限策略7.5%、采信事实7.9%、同事件冲突12.8%、身份桥8.1%，全部不高于30%。

- 静态发布审计：20/20 PASS，100题，公开等级泄漏0。
- 快捷方式审计：PASS；精确题干重复0，精确生成非规则文本重复0。
- L3–L5字面top-k证据召回：22.8%/20.4%/17.4%。
- L5前20%文档的必要文档召回：30.0%。
- Oracle：20个batch全部OK；事实、正span、排除span、edge、完整链和事实+完整链均为100%。
- 可复现性：两个独立构建目录的MANIFEST SHA-256一致。
- 全仓回归：107/107 PASS。

## 仍未解决的门槛

R26.6降低的是模板捷径风险，不等于已经达到强模型事实宏准确率65%以下或相邻等级至少8个百分点。SiliconFlow目录中的免费模型可见，但该账户在生成前统一返回HTTP 402；两次探测均为0 token、0费用、0语义覆盖。余额状态未变化前不再重复请求。

下一步有效动作是完成五场、协议有效的免费或低成本哨兵，分别检查事实、正证据、排除证据、类型边和完整链的等级曲线。只有经验结果稳定后，才应决定继续修改文本还是扩到220场。
