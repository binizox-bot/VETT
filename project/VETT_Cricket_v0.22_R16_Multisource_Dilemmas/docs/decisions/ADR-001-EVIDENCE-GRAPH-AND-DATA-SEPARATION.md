# ADR-001：证据图、失败关闭与公开/私有物理隔离

- 状态：Accepted
- 日期：2026-10-17

## 背景

多来源文本到表格任务需要同时提供高难度冲突和可审计唯一答案。若把权威顺序、结构化修订边或金标放入公开输入，会产生捷径；若只在私有代码中规定规则而没有公开文本证据，任务又会变成不可验证的隐藏规则猜测。

## 决策

1. 公开层只保留求解所需的自然语言证据和空目标结构。
2. 私有层保存可执行声明图、金标、跨度哈希、依赖和决定性支持。
3. 每条影响答案的私有图边必须由公开文本中的肯定式跨度见证。
4. 解析器遇到未知引用、循环、冲突活跃值、缺失见证或不完整依赖时失败关闭。
5. 发布时同时执行决定性跨度删除、图边消融、算术一致性、泄漏检查和文件哈希验证。
6. 各版本输出只写入新的非空拒绝目录，历史发布保持不可变。

## 后果

优点是每个答案都能形成从公开文本到结构化声明、状态转换、决定性支持和金标的可复核链条，并能自动发现篡改或语义断裂。代价是发布体积、生成复杂度和审计成本增加，而且必须严格隔离私有文件；即便全部机器门槛通过，也仍需把盲测性能与人工自然度作为独立、尚未完成的证据类型。
