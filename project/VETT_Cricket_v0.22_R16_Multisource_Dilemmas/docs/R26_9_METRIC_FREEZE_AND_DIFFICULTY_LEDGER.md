# R26.9 指标冻结与难度特征账本

## 1. 本阶段解决什么问题

本阶段不再凭单次模型分数反复改难度，而是先固定“什么叫难、什么结果可用于改数据”。冻结发生在下一次强模型 Gate3 之前，因此后续结果不能反向修改指标口径。

这里严格区分两类量：

- **模型表现指标**回答模型做对了多少，是论文结论的来源。
- **结构难度特征**回答题目放入了哪些负担，是数据构造与审计工具，不能替代模型实验。

机器可读合同分别位于 `design/r26_9_metric_contract.json` 和 `design/r26_9_difficulty_feature_contract.json`。

## 2. 冻结后的主指标

主指标是 `decision_field_level_macro_accuracy`：每题比较 12 个规范化事实字段；先在每个私有等级内求字段准确率，再对 L1–L5 等权平均。当前每级题数和字段数相等，因此它与全体字段微平均数值相同；实现仍显式核对二者，未来一旦样本失衡就会拒绝判定。

选它而不选“整条记录全对率”的原因是：整条记录只要错一个字段就记零，适合做严格描述，但对五级难度校准过于离散。证据 span、拒绝证据、类型化边、事实—证据联合正确率等仍完整报告，但不参与主难度闸门，防止一个混合总分掩盖具体能力缺陷。

强模型目标区间冻结为 45%–65%，L1 准确率下限为 60%，相邻等级目标下降为 8 个百分点。

## 3. 三阶段判定权限

| 阶段 | 样本 | 允许得出的结论 |
|---|---:|---|
| 单场协议 Gate | 1 场 | 只判断请求、返回、格式和证据图协议是否完整；禁止判断难度 |
| Sentinel5 | 5 场 | 只做方向筛查：主指标落入目标区间、L1 达标、至少 3 个相邻下降、平均下降至少 8 点 |
| Pilot20 | 20 场 | 正式校准：四个点估计均至少下降 8 点，并完成成组 bootstrap 不确定性检验 |

Pilot20 使用固定随机种子 26091、10,000 次重采样。抽样单位是“比赛块”：同一场的 L1–L5 一起被抽中，保留场内配对关系。95% 双侧百分位区间使用线性插值，至少三个相邻差值的下界必须大于零。只有两个不同强模型家族都完成有效 Pilot20，才允许进入 220 场扩展冻结。

## 4. 正式计分资格

以下条件缺一不可：全部计划比赛和目标返回、所有 batch 为 `OK`、无服务商截断、无 JSON 补括号修复、通过本地 schema 与证据图检查、未提前停止。协议无效结果单独报告可用性，不折算为事实错误，也不得用于修改数据难度。

免费 4B、事实字段诊断恢复、单场结果都被明确排除在强模型难度校准之外。这样既保留调试价值，又避免低能力模型或格式故障把数据错误地推向更难。

## 5. 私有难度特征账本

账本粒度是一题一行，共 100 行，覆盖 20 场、五级各 20 题、25 个场景族各 4 次。账本只放在分析目录，不进入公开输入。

六类结构轴及其含义如下：

| 结构轴 | 主要组成 | L1 → L5 均值 |
|---|---|---|
| 实体绑定 | 身份跳数、同构干扰项 | 0.100 → 0.367 → 0.467 → 0.733 → 1.000 |
| 权威冲突 | 权威裁决、拒绝证据 | 0.125 → 0.125 → 0.125 → 0.875 → 1.000 |
| 规则推理 | 推导深度、算子成本、交互数 | 0.317 → 0.619 → 0.661 → 0.681 → 0.764 |
| 时间状态 | 时间切换深度 | 0.000 → 0.000 → 0.500 → 0.500 → 1.000 |
| 证据负载 | 必要证据、跨文档数、类型边数 | 0.422 → 0.625 → 0.743 → 0.785 → 0.850 |
| 反事实负载 | 干预路径、影响半径 | 0.444 → 0.589 → 0.667 → 0.667 → 0.767 |
| 综合结构指数 | 上述六轴等权平均，仅供审计 | 0.235 → 0.388 → 0.527 → 0.707 → 0.897 |

审计只要求综合结构指数严格递增、证据负载不下降，不要求每个原始特征都机械递增。当前账本有意保留算子数、证据分散度和反事实影响半径等局部交叉；这让相邻等级通过不同机制变难，降低模型按长度或固定模板猜等级的风险。

## 6. 已通过的稳定性门槛

- 100 行、20 场、L1–L5 各 20 行。
- 25 个场景族，每族恰好出现 4 次。
- 所有嵌入式 `difficulty_vector` 均可从公开实例与私有答案重新计算，漂移为 0。
- 公开问题中难度标签泄漏为 0。
- 完全重复特征行为 0。
- 七个归一化轴均落在 `[0, 1]`。
- 同一源数据与合同重复构建时，JSONL、CSV 和审计报告逐字节一致。
- 源 release、两份合同和账本均记录 SHA-256，可追踪后续漂移。

当前账本 SHA-256 为 `3e5fcb4113c9a37f05300712cfd9f71c07fc5cd36d9a46b1577b6c3dd0a0d134`；修改合同后必须重新生成审计，最终交付以最新审计文件中的哈希为准。

## 7. 下一步的唯一合理动作

先保留数据不变，执行一场强模型协议 Gate。只有协议完全通过，才运行固定五场 Sentinel5；只有 Sentinel5 有效且具备方向性，才值得购买 20 场强模型 Pilot。若协议失败，只修评测链；若主指标高于 65%，只增强仍被答对题目的机制；若低于 35% 或 L1 低于 60%，停止加难并排查地板效应；若出现等级倒挂，只修改倒挂的相邻等级。任何修改都必须生成新版本合同引用和新账本，不能覆盖本次冻结证据。
