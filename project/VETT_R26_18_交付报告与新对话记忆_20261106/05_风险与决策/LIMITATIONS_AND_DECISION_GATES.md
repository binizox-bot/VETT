# 局限、风险与决策门

## 当前证据缺口

### 1. 完整五场仍缺失

R26.16只有4/5场可评分；R26.17的一次新五场在第一场发生重复证据边后停止；
R26.18尚未发出provider请求。因此不能报告完整、同协议的Sentinel5结果。

### 2. 模型覆盖单一

主要外测来自`zai-org/GLM-5.3`/GLM-5.3-Flash同一模型家族。当前结果不能代表
所有闭源强模型或不同解码风格。

### 3. 难度曲线未稳定证实

四场子集出现L2→L3倒置10.42个百分点，且每级缺一个匹配锚点单元。倒置可能来自
样本组成、协议失效或真实难度设计，不应在完整匹配结果前武断修改文本。

### 4. 20场统计校准未完成

还没有在冻结R26.18协议下完成Pilot20，也没有按比赛分块的bootstrap置信区间和
跨模型复验。

### 5. 220场最终发布未完成

R26.15已通过220场流式可扩展性和因果审计，但没有把最终高难度版本完整物化、
人工抽检、独立复标和打包发布。

### 6. 自然性与标注仍需人审

机器门能够检查结构、因果、引用和答案一致性，但不能替代母语自然性审阅、板球专家
复核和双人独立标注一致性。

## 外测前硬门

只有全部满足才值得重新付费：

1. 使用R26.18冻结合同和同一五场匹配设计；
2. 新配置与阻断配置除授权位和全新空输出目录外没有语义差异；
3. 零请求预检、202项测试和请求哈希检查仍通过；
4. 上下文、输出余量和1.4元硬上限未退化；
5. `max_retries=0`、防重复请求、首个硬失败停止仍开启；
6. 用户在当前新对话中明确授权费用。

## 结果后的决策门

| 观察 | 决策 |
| --- | --- |
| 主事实指标>65%，协议与匹配完整 | 只增强模型真实解决的机制；先做题级错误归因，禁止全局盲目加噪 |
| 45%–65%，至少3个相邻下降且平均下降≥8个百分点 | 难度窗基本成立，不继续无目的加难；优先扩Pilot20和第二模型 |
| <45%且大量题事实与证据同时为0 | 检查是否过难、规范负担过大或任务不可学，而不是庆祝低分 |
| 相邻等级倒置 | 只审计倒置级的匹配锚点、情景组成和可见线索；不要整体重写五级体系 |
| 语义较好但服从性差 | 优化输出协议或分开报告；不改金标来迎合provider |
| provider错误/截断 | 记为执行失败，不能记成模型语义零分，也不能自动重试烧钱 |

## 论文级发布门

- 冻结版本号、schema、指标和拆分；
- 220场最终候选物化并通过机器门；
- 至少一轮分层人工抽检与独立复标；
- Pilot20置信区间；
- 至少第二模型家族；
- 数据卡、许可、局限、成本和可复现脚本；
- 公布失败样本时完成隐私与授权审查。
