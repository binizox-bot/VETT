# 指标解释与论文报告边界

## 为什么不能只看字段准确率

12字段中包含大量恒零或多数值字段，因此71.67%的字段准确率并不等价于模型真正
恢复了71.67%的关键信息。四场子集中：

- 原始字段：71.67%；
- 信息字段：62.22%；
- 值平衡信息字段：38.83%；
- 整记录：20%。

论文中应同时报告这四类数字，并解释各自回答的问题：

- 原始字段用于与冻结主合同保持可比；
- 信息字段降低恒零字段掩盖；
- 值平衡指标降低多数值先验；
- 整记录要求一次恢复整个事实结构。

## 为什么证据边必须分组

总体类型边包含许多可由角色模板猜出的机械拓扑。R26.15新增内容依赖边后，即使删除
全部内容边，总体边F1仍可能很高。因此必须同时报告：

- 总体类型边F1；
- 内容依赖边F1；
- 内容边问题宏、干预字段宏和场景宏；
- 事实+完整链exact。

目前外测中事实+完整链一直为0%，说明模型即使能得到部分事实或部分边，也没有稳定
构造完整证明链。

## 五级难度判定

目标是强模型事实答案宏准确率约65%以下，并希望相邻等级平均保持约8个百分点区分。
冻结screen要求：

- 主字段指标位于45%–65%目标区间；
- 四个相邻差中至少3个为正；
- 平均相邻下降至少8个百分点。

但screen不等于正式统计结论。正式判断至少还需要：

- 完整5场匹配锚点；
- 不把协议失败当语义零分；
- 对Pilot20做按比赛分块的bootstrap置信区间；
- 第二模型家族验证方向一致性。

## 输出服从性与语义能力

R26.18不把重复证据等同于“证据完全错误”，也不把它静默忽略：

- 集合语义指标测模型选了哪些独特证据；
- 服从性指标测模型是否按要求只输出一次；
- 联合指标要求两者同时正确。

这三类结果必须并列，不允许只挑最好看的一个。

## 推荐论文表格列

| 维度 | 推荐主列 |
| --- | --- |
| 事实 | 原始字段、信息字段、值平衡信息字段、整记录 |
| 状态/反事实 | 状态准确率、反事实字段、反事实整记录、成对exact |
| 证据 | 正span F1、排除F1、类型边F1、内容边F1 |
| 联合 | 完整链exact、事实+完整链exact |
| 可靠性 | 协议完整率、题级服从率、未知证据题率 |
| 成本 | 输入/输出token、实际费用、失败请求数 |

## 禁止的写法

- “GLM在五场上只有71.67%”：实际是4/5可评分子集，不是完整五场。
- “新协议修复后模型得分上升”：后验回放不是正式新请求。
- “重复边不影响结果，所以可以忽略”：它仍是独立服从性失败。
- “数据达到五级稳定区分”：完整校准尚未完成。
- “220场R26.15已发布”：目前是流式预检通过，非最终物化发布。
