# 外部效度声明（External Validity）

## 1. 结论先行

R28 是**半合成诊断基准**，不是真实板球分布样本。本文所有主结论只针对“R28 构造下可分解的误差来源”，**不外推到**真实比赛、真实裁判行为或真实球员能力。

## 2. 半合成边界（与数据卡 B1 一致）

- 220 场源素材是虚构场景，且源侧只有**局级聚合**，没有逐球事实明细；每题的 `solver_facts` 由模板/定向枚举注入。
- 发布版/对照版只保证 facts 与 12 字段记录相同；公开文本是操纵变量。
- 构造配额（status/dismissal/ledger 分布）是设计选择，不是自然频率。
- 因此以下外推都**不成立**：
  - “R28 上模型准确率 = 真实比赛准确率”；
  - “R28 分布 = 板球自然分布”；
  - “R28 的难度 = 真实卷宗难度”。

## 3. Cricsheet 接地方案（附录级可选，不作主结论）

Cricsheet 有公开逐球数据，可用于把生成器锚在真实分布上，但本交付**没有联网、没有下载、没有使用**；仅作为未来工作的可选附录。

若未来接入，最小方案：

1. **许可**：先确认 Cricsheet 许可与署名要求，在数据卡声明来源/衍生关系；不把 Cricsheet 原始文件再分发，只发布派生统计/生成器。
2. **解析**：将逐球 delivery 解析为 R28 的 `solver_facts` 子集；对字段缺失/歧义做显式映射，不静默填充。
3. **接地**：只把 Cricsheet 用于（a）边际分布对齐检查、（b）真实 delivery 的可达性 sanity check、（c）作为外部测试集（不与 R28 训练/调参混用）。
4. **重验**：用同一 solver 重推记录；对无法映射的 delivery 报 `UNMAPPED`，不强行转成 R28 记录。
5. **报告**：外部结果只放附录，标注 “exploratory, not preregistered”；主结论仍基于 R28 的预注册分析。
6. **不声称**：不因 Cricsheet 接入就声称“真实世界难度”或“人类金标”。
