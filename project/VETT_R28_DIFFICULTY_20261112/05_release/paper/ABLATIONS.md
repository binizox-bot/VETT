## 2. 双渲染消融（已执行，A1）

**设计**：同一 `solver_facts` + 同一 12 字段记录，渲染成发布版（D1–D4 剂量）与对照版（四剂量全 0）；公开文本是唯一操纵变量。不是“换数据”，也不是“换模型”。

**读数**：

- hard 信息字段 accuracy **0.595611**（1710/2871；Wilson [0.577543, 0.613424]）
- control **0.601184**（1726/2871；Wilson [0.583149, 0.618949]）
- 配对 drop **0.557297pp**；item bootstrap 95% CI **[−0.801115, +1.846047]**
- 方向：control 更准 69 / hard 更准 47 / tied 203；符号检验 p=**0.050730**
- 整记录 exact：**5/638 = 0.78%**
- 预注册判定：**DIRECTION_ONLY**；`harder_claim_permitted=false`

**解释（写进论文）**：这个消融**没有**显示“发布渲染更难”；只能作为“呈现层变化与准确率差异不可区分于 0”的读数。不得把它包装成难度证据。

1. 已执行消融必须给 n、点估计、95% CI、效应量；未执行写 `NOT_RUN`。
