# RELATED WORK（三条线 + 定位）

> 这是投稿骨架，不是完整综述。引用格式待补；所有实验数字仍只来自 eval_runs / gate_ledger。

## 1. 规则推理 / 多跳证据基准

**代表工作（待补引用）**：bAbI / CLUTRR 风格的合成关系推理；HotpotQA / 2WikiMultiHopQA 的多跳问答；RuleTaker / ProofWriter 的规则蕴含；法律/合同领域的规则适用与案例推理基准。

**已有做法**：给定文档/规则，要求模型输出答案或证明；主要报告端到端准确率、检索命中、或证明正确率。

**差距**：
- 这些基准通常不区分“证据可见但作用域错”“规则版本选错”“引用了装饰性规则但结论不变”等失败来源；端到端分数把它们混在一起。
- 规则文本常被当作静态上下文，缺少**版本/生效时间/冲突裁决**的可控因子；多跳证据研究多关注“找到链”，较少把“最小承载证据”作为独立端点。
- 排行榜驱动的最优分数不能回答“模型是否真的依赖证据”，因为题面/先验/族名都可能绕过卷宗。

**R28 的定位**：不提供更大规模或更高难度的排行榜；提供一个可分解的**诊断对象**，用双渲染、剂量、证书与 rule_path 把上述失败来源拆开，并预注册“难度不成立”的负结果（E1/E2/E3）。

## 2. 可解释性 / 证据归因

**代表工作（待补引用）**：ERASER 风格的 evidence sufficiency/ comprehensiveness；归因/显著性方法；证书/证明生成；rule-based explanation 与 counterfactual ablation。

**已有做法**：用删除/保留证据衡量归因，或用模型自生成的解释/证书评估“看起来合理”。

**差距**：
- “证据存在”≠“证据必要”：模型可能引用大量规则 span，但删除其中大多数不改变记录；需要**逐算子消融**与“承载/装饰”分离。
- 模型自写解释/证书可能复制输入或给出漂亮但错误的理由；不能把模型输出当作金标。
- 现有评测常把解释质量与最终答案正确性混在一个分数里，缺少“同一 facts、不同呈现”的对照。

**R28 的定位**：证书 `rule_path` 只列承载算子，装饰性行为单独登记；双渲染保持 facts/记录不变，只改呈现层；E1 是这个对照的直接读数。R28 不声称证书长度/规则引用数量等于解释质量。

## 3. 校准 / 弃权 / 选择性预测

**代表工作（待补引用）**：selective prediction / risk-coverage；calibration（ECE、temperature scaling）；abstention 与 deferral；LLM 自评/自一致性。

**已有做法**：用置信度阈值决定弃权，报告 risk-coverage 或校准误差；或用模型自报 confidence/unsure。

**差距**：
- 自报置信度/弃权标签可能没有区分度；在本交付的受限设置中，唯一可执行模型是 7B Q4、零付费禁止云端，跨模型区分度 **E5 = UNTESTED**，不能把单模型 calibration 当作通用结论。
- 小样本的 abstention 一致率只能描述性报告；不能当质量门。
- 校准通常需要可重复的 scoring 与解析器版本绑定；缺少这些时，risk-coverage 曲线不可比。

**R28 的定位**：把 E5 明确标为 UNTESTED，撤回区分度主张；把“弃权/一致性”留作未来工作，不用未测数字填充。可复现的只有评分重算与解析器绑定（R-R7）。

## 4. 与本工作最接近的差异（一句话）

现有工作多在“更大/更难/更高分”的轴上竞争；R28 在“**同一 facts 下可分解的失败来源**”轴上提供仪器化诊断，并把负结果、基线矩阵、失败 gating 与人工双标阻断项一并发布。
