## 0. 一句话结论

**目标部分成立，设计基本有效但有两处必须修正，可持续迭代且扩张路径明确。**

## 2. 目标有效性

### 2.1 成立的

**（a）金标可机械重推。** `solve(solver_facts) == decision_record_flat` 在 100 题上全部一致。这意味着数据集的"正确答案"不是人工声称的，而是可被独立程序复算的。大多数基准做不到这一点，这是本项目最值得保留的资产。

**（b）无答案泄漏。** 逐题检查 public 卷宗，`solver_facts`、`decision_record_flat`、`minimum_evidence_spans`、`difficulty_vector` 全部 0 命中；100 题里没有一题的 `question_id` 与答案组合同时出现在公开文本中。

**（c）呈现剂量与准确率的关系尚未确定（初稿曾误判为已证）。** 有 6 组事实集被跨等级复用：

```
L3_DEAD_BEFORE_RUNOUT / L4_REVIEW_DEAD_SEQUENCE / L5_RUNOUT_LATER_BOUNDARY  → 同一事实、同一记录
L2_WIDE_STUMP / L4_REVIEW_WIDE_STUMP / L5_WIDE_STUMP_REVIEW                  → 同一事实、同一记录
L3_CATCH_BOUNDARY / L4_REVIEW_CATCH_CONTROL                                  → 同一事实、同一记录
```

这些题的事实与答案完全相同，只有呈现结构不同。本报告初稿据**整级宏准确率** 63.3% / 60.0% / 51.7% 推断"剂量杠杆已验证"，**该推断是错的**：整级平均混杂了场景、比赛与抽样误差，不是配对比较。t3 改为同事实组逐对比较后得到 **5 降 / 4 升 / 1 平，均值 −3.3pp，符号检验 p = 0.50**——**没有证据表明剂量有效**。该主张已降级为 UNTESTED（HYP-R28-DOSE），由 E2 负责检验，本计划不再预设它成立。

### 2.2 不成立的

**（a）信息量几乎为零。** 100 道题里只有 **17 个互异事实集、16 个互异记录**。每族 4 个副本的事实**完全相同**，只有背景比赛不同。也就是说：重复测量的是同一道题。

**（b）族名决定答案。** 25 个族名到记录的映射是常数（25/25）。`answer_space_audit.json` 自己已经写明：*"Naming the scenario family determines the entire 12-field record... field accuracy alone cannot distinguish 'derived the record' from 'identified the scenario'."* 一个能分类族名的模型直接拿 100%。

**（c）求解器是浅的。** 求解器是**单球裁决**：26 个事实字段、单函数、约 20 条规则分支。它不是多跳推理机，是规则查表器。**任何"深度推理"的表述都会在审稿时被质疑。**

**（d）三个账本字段恒零。** BYE / LEG_BYE / PENALTY 在 100 题里全为 0，而可达空间里分别有 57 / 26 / 84 个非零记录。这不是数据分布问题，是生成器覆盖面问题。

### 2.3 结论

**"让数据集更难"这个目标本身不成立**，因为它预设数据集已经测到了东西。**成立的表述是：把数据集从"分类 25 个情景"改造成"在冲突证据中恢复事实并裁决"，并让每一步可被机械验证。**

## 3. 设计有效性

### 3.1 双渲染：机器已存在

`generator.py` 的渲染路径直接读取五个结构参数：

```python
if scenario.alias_hops >= 1:      # 跨文档别名跳
if scenario.alias_hops >= 2 or scenario.temporal_joins:   # 修订链
if scenario.scope_decisions:      # 权威裁决
shadow_count = scenario.isomorphic_distractors            # 同构干扰项
```

也就是说：**同一组事实，通过改变这五个参数，就能渲染出不同难度的卷宗**。t5 不需要发明机制，只需要把"每族固定一个结构元组"改成"每实例按剂量分配结构元组"。这是配置工作量，不是研究工作量。

### 3.2 必须修正之一：机制数说错了

我在提案里写了 5 个机制，其中 **M1「推导深度」不是可调变量**：

- `rule_operators` 是模板里手写的常量（L1=1、L2=3、L3=2、L4=3–4、L5=4）；
- 记录由事实唯一决定，事实不变则记录不变，**推导步数也不变**。

所以真正的可调剂量只有 **4 个**：

| 修正后 | 对应代码参数 | 剂量 0 / 1 / 2 |
|---|---|---|
| **D1 证据跳数** | `alias_hops` | 0 / 1 / 2 |
| **D2 修订链** | `temporal_joins` | 0 / 1 / 2 |
| **D3 权威裁决** | `scope_decisions` | 0 / 1 / ≥2 源冲突 |
| **D4 干扰同构度** | `isomorphic_distractors` | 0 / 1 / ≥2 |

**"推导深度"降级为描述性标签，不再是机制。** 这比原来诚实，也更好实现。

### 3.3 必须修正之二：两个验收指标互相冲突

提案里同时要求：

- 硬验收 A：`互异完整记录 ≥ 0.9 × 题数`
- 硬验收 B：每题有 shallow / hard 两份渲染，事实与金标相同

**这两条在数学上不能同时成立。** 双渲染产生的是同一记录的两个副本：160 题如果都是 80 个实例 × 2 渲染，互异率上限只有 0.5。

**修正方案：把"发布集"和"实验集"分开。**

| 集合 | 内容 | 验收 |
|---|---|---|
| **发布集**（`public/` + `private/`） | 160 题，**一题一记录**，题均分配剂量 | 互异率 = 1.0 |
| **对照集**（`variants/`） | 每题一份配对渲染（剂量取另一端） | 事实与金标逐字节相同 |
| **实验集**（`eval_runs/`） | 160 × 2 = 320 次推理，题内配对 | McNemar |

这样"互异记录 ≥0.9"与"同金标双渲染"各自成立，互不干扰。R26.15 的目录结构本来就有 `variants/`，不需要新结构。

## 4. 可迭代性

### 4.1 事实空间是够用的

| 指标 | 值 |
|---|---|
| `FACT_DOMAINS` 字段数 | 26 |
| 笛卡尔积上界 | 1,811,939,328 |
| 随机 2 万组事实 | 全部合法（0 异常） |
| 得到互异记录 | **156** |
| `total_runs` 取值 | 0–17 |
| 同记录对应多事实集 | 0（记录对事实是单射） |

**结论（已被 t4 探针修正）：随机抽样严重低估了空间。** 2 万次随机抽样只得 156 个互异记录，但**分层定向枚举**（15,840 组构造事实、0 失败、67 层）给出可达互异记录**下界 761**。因此：

- ✅ 不但撑得住 160 题，**也撑得住 320 / 400 题**（N=320 需 392 个记录 ≤ 761，约 2 倍余量）；
- ⚠️ N 的上限约 640（需 744 ≤ 761），再往上才需要扩求解器；
- ❌ **本报告初稿"160 已接近天花板"的结论作废。** 教训：随机抽样不能用来估计可达空间，必须做定向枚举。

### 4.2 常数字段可以彻底修掉

随机采样下非零覆盖：

| 字段 | 非零记录数 / 156 |
|---|---:|
| `ledger.BYE` | **57** |
| `ledger.LEG_BYE` | **26** |
| `ledger.PENALTY` | **84** |

现在 100 题里这三个字段全是 0，是生成器没覆盖，不是空间不够。**修复是可行的，而且代价极低。**

### 4.3 一个必须处理的陷阱：随机抽样会重演退化

随机 2 万组事实的 `dismissal` 分布：

```
NONE    115 / 156  (74%)
RUN_OUT  33
STUMPED   3
BOWLED    2
CAUGHT    2
LBW       1
```

**直接随机抽样会把 `dismissal` 又变成一个准常数字段**，重演当前缺陷。所以 R28 的生成器必须**分层定向枚举**（先枚举目标记录形态，再反解事实），不能随机采样。

### 4.4 最小充分事实集的陷阱

贪心算法把 24 个事实键压到 13 个，但**只在当前 100 题内成立**：在 4000 组随机事实上，13 键与 24 键只有 **27.8%** 一致。

原因是现有语料里某些组合从未出现（例如 `appeal_made=false` 与 `dismissal_candidate=LBW` 从未共存），贪心把"样本内无用"误判成"全局无用"。

**含义有两层：**
1. 不能把"13 个事实"当成任务的真实复杂度写进论文；
2. 现有语料的**事实组合覆盖是稀疏且相关的**，这既是捷径风险，也是扩张机会——R28 应当主动覆盖这些从未出现的组合。

### 4.5 底料不是瓶颈

220 场源文本：每场 `commentary.txt`（5.5–7.3 KB）+ `evidence_chain.md` + `scorecard.md` + `meta.json`。R26.15 每场卷宗 39 个文档、约 24 万字符。**220 场足够渲染 160 题所需的背景，素材不构成约束。**

但要注意：220 场里没有逐球事实明细，只有局级聚合。所以**事实必须由场景模板注入，不能从真实比赛抽取**。这一点必须在数据卡里写明，否则会被质疑"半合成"的边界。
