| L2 | Bowling reconciliation | Requires understanding that byes and leg-byes are not charged to bowlers. | Harborline bowlers concede 134 bowler-charged runs while Atoll Bay total 136 because two runs are byes/leg-byes; Atoll Bay bowlers concede 136 charged runs while Harborline total 137 because one run is a leg-bye. |
| L2 | Ball-count consistency | Requires checking that batting balls match legal deliveries in each innings. | Atoll Bay batters face 210 balls across 35.0 overs; Harborline batters face 193 balls across 32.1 overs. |
