# R26.15静态证据链复核

## 结论

R26.15的静态一致性、确定性、Oracle闭环、内容依赖边敏感性和220场流式可构造性证据完整，但这些证据不能替代强模型经验难度、人工准确性或发布许可。

当前正确状态仍是：静态候选通过、经验难度阻断、220场未物化。

## 不得被总体PASS掩盖的警告

### 内容机会量不平衡

内容边机会量的等级比为3.0。因此按等级比较内容边exact或F1时必须同时报告机会量和字段/情景切片，不能把该指标单独解释成L1–L5经验难度顺序。

### 总体边F1掩码

删除全部内容依赖边后：

- 总体最小证据边F1仍为0.93896；
- 内容依赖边F1为0；
- 事实—证据链联合exact为0。

所以后续正式报告必须并列给出总体边F1、内容依赖边F1、端点恢复率和联合链exact。只报告总体边F1属于不完整测量。
