## 3. 固定主指标

`decision_field_level_macro_accuracy`：每题12个规范化事实字段，先在私有等级内平均，再对L1–L5等权平均。

- 强模型目标区间：45%–65%；
- L1最低准确率：60%；
- 四个相邻点估计下降均至少8个百分点；
- 至少3个相邻差的95%置信区间下界大于0。

不得在看结果后改主指标、等级权重、阈值或样本。

## 4. 固定统计合同

- bootstrap次数：10,000；
- 随机种子：26091；
- 重采样单位：比赛块，保留该比赛全部五个等级；
- 区间：双侧percentile 95%；
- 分位数方法：在索引`(n-1)*p`上线性插值；
- 20场重复控制若存在，只作一致性检查，不得冒充独立样本；
- 题级重采样不得替代比赛分块bootstrap。

## 5. 正式资格门

- 20个预注册比赛和100题全部返回；
- 每个runner batch状态均为`OK`；
- 无截断、JSON修补、缺题、多题、身份冲突或图/schema硬失败；
- 请求哈希与预检一致；
- 不依赖从`INVALID_OUTPUT`恢复的结果；
- 完整报告可用性、硬协议、服从性和语义四轨；
- 内容依赖边机会量和测量掩码警告必须单列。

任一门失败时，结果只能用于可用性或诊断，不可补成正式Pilot20。

## 6. 必报结果

- 主指标、L1–L5值和四个相邻差及95%区间；
- 按12字段、5等级、5锚点、25情景家族、关系、span和内容依赖边切片；
- 总体边F1、内容依赖边F1、端点恢复率、事实—证据链联合exact并列；
- 事实、反事实、状态、正/排除证据和服从性；
- provider可用性、token、缓存、延迟、费用和异常；
- 正式、诊断和探索性结果分层。

## 7. 调整权限判定

单一强模型家族只有在同一预注册机制至少影响4题、至少2个锚点、全部batch为OK且报告保持锚点平衡时，才允许建立shadow；不得晋升。

第二强模型家族必须先在未改变的R26.15上验证同向触发。只有两家族同向、每家族至少2锚点支持、满足地板效应限制并通过fresh shadow Sentinel，shadow才可能晋升。
