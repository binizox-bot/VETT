## 人工规范的待批准项

人工规范目前是草案，不得写成已冻结事实。正式开始前需用户和领域专家批准：

- 98%门的计算单位和分母；
- 四核心维度是否分别设门；
- 抽样框、分层变量、随机种子和样本量/功效；
- 缺失/不确定判断的处理；
- kappa/alpha及集合指标的报告方法。

本草案推荐对100题Pilot的值、作用域、规则版本和最小证明分别计算题级exact agreement，每个维度至少98%，全部分歧仲裁，关键错误零容忍。该推荐只有经批准后才能进入正式合同。
